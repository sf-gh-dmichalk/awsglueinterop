Blocked / Private Preview Paths

  • TABLE_FORMAT=HIVE — Catalog integration with Hive table format is in Private Preview; cannot create Iceberg tables from Hive-registered Parquet via Glue catalog
  • TABLE_FORMAT=NONE (Parquet Direct) — Direct Parquet read through catalog integration is in Private Preview
  • Catalog-Linked Database via Glue REST — Requires Lake Formation admin privileges to configure the REST-based catalog endpoint
